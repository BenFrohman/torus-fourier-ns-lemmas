# Provenance hashes

These files are SHA-256 integrity fingerprints of the repository tree as of commit `09819f2`
(`PROVENANCE_HASHES_REPORT.md` was generated at the older commit `c18f2e1` and covers only 4 modules).
The files were renamed afterwards; recorded paths refer to the original names. They let anyone check that
a file is byte-identical to an archived version. They are **not** a certificate of mathematical
correctness, peer review, or acceptance by any body. Correctness evidence is the Lean build plus the axiom
report in `AXIOMS.md`, reproduced by CI.
